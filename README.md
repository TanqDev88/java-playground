# Java Playground

A personal repository for learning and practicing Java fundamentals through small exercises, coding challenges, and language feature demonstrations.

The goal of this project is to build a solid foundation in Java before moving on to more advanced topics such as Spring Boot, databases, concurrency, and software architecture.

---

## Objectives

- Learn Java syntax and core language features.
- Practice object-oriented programming (OOP).
- Solve programming challenges from platforms like Codewars.
- Explore Java standard libraries.
- Build a collection of reusable examples for future reference.

- Lambdas

## Running the Tests

Using Maven:

```bash
mvn test
```

Or directly from IntelliJ IDEA using the JUnit test runner.
